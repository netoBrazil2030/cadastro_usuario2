Resumo do Código , bando de dados sqlserver e sistema web.
1. O usuário acessa /Contato/Index.
2. O Controller consulta a tabela e pega a lista de Contato.
3. O Controller envia essa lista para a View, que renderiza o HTML na tela do navegador.

   Tecnologia usado para o desevovimento do sistema de cadastro aonde pode altera , cadastrar , excluir
   nome , e-mail e celular cadastro na lista.
* .net 10 , MVC, Razor, ASPX, Entity Framework, WCF, SQL Server e Visual Studio.
*  HTML, CSS, JavaScript, jQuery e Bootstrap.
